# Nights to Globalist

A phone-first tracker for a World of Hyatt status challenge: how many qualifying
nights are credited, how many are still to book, what that costs, and — the part
that actually loses people their status — whether Hyatt's count still matches
your own.

## Files

| File | What it is |
| --- | --- |
| `artifact.html` | The app. Written as a Claude Artifact fragment: no `<!doctype>`, `<html>`, `<head>` or `<body>` tags, because the Artifact runtime supplies them at publish time. This is the source of truth — edit this. |
| `build-standalone.sh` | Wraps `artifact.html` into a complete HTML document. |
| `index.html` | Generated by the build script. Open it locally or serve it from GitHub Pages. |

Rebuild the standalone copy after any edit:

```sh
./build-standalone.sh
```

## Storage

Published as an Artifact, the app uses the `db` capability, so the challenge
terms, stay ledger and account snapshots follow you across devices. Opened as a
plain file, `window.claude` is absent, every capability call resolves to nothing
and the app falls back to `localStorage` on that one device. Both paths work;
only the syncing differs.

The `sample` capability powers the optional "Ask Claude for a plan" button on the
Advisor tab, and `downloads` powers the CSV export. Where either is unavailable
the app hides or degrades that control rather than leaving a dead button.

## What it deliberately does not do

It never asks for a World of Hyatt password and never logs into the account.
Hyatt publishes no public API for member activity, and automating a login would
mean storing the credential and working around bot protection. Instead the
Account tab keeps dated snapshots of what the account showed, diffs each one
against the last, and reports what posted between checks — plus it flags stays
that have been checked out for ten days without appearing.

## Terms are user input, not assumptions

Every number the app produces is derived from the challenge terms entered on the
Challenge sheet — target nights, window dates, which rates count. Status
challenge offers differ, so the app treats those terms as data rather than
hardcoding a program's rules, and marks the advice items that depend on offer
fine print with a "verify" badge.
